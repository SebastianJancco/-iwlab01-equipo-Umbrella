# 🚀 Sobre el proyecto

**Servilink** es una plataforma web orientada a conectar a personas que necesitan contratar un servicio con **prestadores de servicios locales de Cusco Metropolitano**.

La plataforma busca centralizar la información de diferentes servicios en un único espacio, facilitando que los usuarios puedan **buscar servicios, conocer a los prestadores y enviar solicitudes**.

### 🎯 Problema identificado

Actualmente, las personas que necesitan contratar un servicio local tienen dificultades para encontrar y contactar prestadores confiables, debido a que la información se encuentra dispersa en diferentes medios y no existe una plataforma centralizada que facilite su búsqueda y contacto.

### 💡 Propuesta de solución

Servilink propone un marketplace web que permita:

* 🔎 Buscar servicios locales.
* 📍 Encontrar prestadores dentro de Cusco Metropolitano.
* 👤 Consultar información de los prestadores.
* 📩 Enviar solicitudes de servicio.
* 🗂️ Organizar los servicios por categorías.
* 🌐 Centralizar la oferta de servicios locales.

---

# 🎯 Objetivo principal

Facilitar la conexión entre **clientes y prestadores de servicios locales** mediante una plataforma web sencilla, centralizada y accesible.

### Función central

> **Buscar un servicio local y enviar una solicitud a un prestador de servicios.**

---

# 📌 Alcance del proyecto

La primera versión de Servilink estará enfocada exclusivamente en **Cusco Metropolitano**.

El sistema permitirá a los usuarios buscar servicios y contactar a prestadores mediante solicitudes.

### 🚫 Fuera de alcance

Para esta primera versión no se contempla:

1. Procesamiento de pagos dentro de la plataforma.
2. Gestión de servicios fuera de Cusco Metropolitano.
3. Chat interno en tiempo real.
4. Aplicaciones móviles nativas.
5. Videollamadas.
6. Sistema avanzado de inteligencia artificial para recomendaciones.
7. Verificación oficial o certificación profesional de todos los prestadores.
8. Sistema completo de facturación.
9. Gestión logística o transporte del prestador.
10. Marketplace de productos físicos.

# 🔎 Análisis de referencia

Como parte del análisis observacional se seleccionó **Computrabajo** como plataforma relacionada con el dominio del proyecto.

Se analizaron aspectos como:

* Motor de búsqueda.
* Filtros.
* Organización por categorías.
* Ubicación geográfica.
* Perfiles.
* Intermediación entre usuarios y oportunidades.

El análisis de plataformas de intermediación permite identificar buenas prácticas para organizar servicios, especialidades y ubicaciones dentro de Servilink.
