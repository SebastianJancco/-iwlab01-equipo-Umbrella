# Evidencias

Este directorio contiene evidencias propias del trabajo realizado por el equipo durante el desarrollo del proyecto semestral.

## Índice de evidencias

### 1. Mapa de Ingeniería Web
Evidencia del mapa elaborado por el equipo, donde se identifican usuarios, necesidad, función principal, datos, calidad, seguridad y contexto.

### 2. Análisis observacional
Evidencia del análisis realizado sobre una página web pública relacionada con el dominio de servicios locales.

### 3. Trabajo colaborativo
Evidencias de los aportes realizados por los integrantes del equipo durante la elaboración del diagnóstico y organización del proyecto.

### 4. GitHub
Evidencias relacionadas con la creación del repositorio, ramas, commits, issue y pull request.

## Consideraciones

Las evidencias serán propias del equipo y no incluirán contraseñas, tokens, credenciales, datos personales reales ni otra información sensible.
